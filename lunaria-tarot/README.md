# LUNARIA TAROT

LUNARIA TAROT は、月明かりの雰囲気で3枚引きタロットを楽しめるブラウザアプリです。

外部AI、APIキー、サーバー、課金は不要です。相談テーマと選んだカードをもとに、鑑定文をブラウザ内だけで生成します。

## Features

- 大アルカナ22枚を収録
- 正位置・逆位置に対応
- 恋愛、仕事、人間関係、その他の相談テーマ
- 過去・現在・未来の3枚引き
- ブラウザ内だけで鑑定文を生成
- スマホとPCの両方で利用可能

## How To Use

1. `index.html` をブラウザで開きます。
2. 相談テーマを選びます。
3. 必要であれば相談文を書きます。
4. 裏向きのカードから3枚を選びます。
5. カードをめくり、鑑定結果を読みます。

## Publish With GitHub Pages

専用リポジトリとして公開する場合は、`lunaria-tarot` フォルダの中身をリポジトリのルートに置いてください。

1. GitHubで新しいリポジトリを作成します。
2. `lunaria-tarot` の中身をアップロードします。
3. リポジトリの `Settings` を開きます。
4. `Pages` を開きます。
5. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
6. `Branch` で `main` と `/root` を選び、保存します。
7. 数分後に表示される GitHub Pages のURLを友達へ送ります。
